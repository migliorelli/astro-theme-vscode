# AstroTheme (Unofficial) for VS Code

An **unofficial** VS Code port of [AstroTheme](https://github.com/AstroNvim/astrotheme),
the default colorscheme of [AstroNvim](https://astronvim.com).

Includes four variants: **AstroDark**, **AstroLight**, **AstroMars** and **AstroJupiter**.

> This extension is not affiliated with, endorsed by, or maintained by the
> AstroNvim project or its authors.

## Installation

Open the Command Palette → `Preferences: Color Theme` → pick one of the AstroTheme variants.
